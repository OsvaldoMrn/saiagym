# API de predicción de series

1. pip install flask scikit-learn pandas numpy uvicorn

2. uvicorn hypertrophy_api:app --reload --host 0.0.0.0 --port 8000

3. correr la app en expo con npm start o npx expo start

4. Verificar la url de la computadora dentro del archivo ExerciseScreen.js, en la función predecirSiguienteSet dentro del componente renderExerciseTable
